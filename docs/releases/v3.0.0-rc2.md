# BlueFire Nexus 3.0.0-rc2 (earlier product, superseded)

**This release is the earlier product, and it is superseded.** In November 2026
the repository's `main` branch was replaced by a different, smaller thing: a
test bench for defenders that runs published attack tests on a disposable lab
target and reports what the defenses on that target saw. The
[README on `main`](https://github.com/Moneer-S/BlueFire-Nexus#readme) describes
it and links the runs that show what it does.

The earlier product is no longer developed and gets no fixes. Its code stays in
the git history at the tag `v3.0.0-rc2`, and the files attached to this release
stay as they were published. Nothing below describes what `main` holds today.

The notes of the release as it was published on 25 October 2026 follow. What
they say was verified is the earlier product's own statement from that time.
None of it is linked to a run that shows it, so read each such statement as
not shown.

---

RC2 is an experimental prerelease for local, authorized security testing. It connects experiment planning, reviewed runs, detection work, and saved comparisons. Manual editing and simulation remain available with AI Off.

## What changed

- **Build and inspect together.** Navigate connected steps, conditional routes, and data dependencies, or switch to the ordered Steps view. Inspect Method, Evidence, and Parameters together. Moving or arranging steps preserves execution semantics, and layout changes support Undo.
- **Use a contextual Assistant.** Requests retain their captured context as you navigate. Results provide review links and available stop or recovery controls. Model, destination, data, authorization, and usage settings remain accessible beside the conversation.
- **Understand readiness and outcomes.** Setup distinguishes configured resources from task readiness. Run review separates the recorded path, runner-reported outcomes, independent observations, and cleanup.
- **Keep rules and comparisons connected.** Detection Lab presents rules beside their source evidence and evaluation results. Compare leads with the conclusion and source runs. Reopen saved experiment versions, rules, evaluations, and comparison snapshots.

## Install

Use 64-bit Python 3.10 or newer and the wheel matching your operating system and architecture. The package includes the browser interface, examples, and native runner; no frontend build is needed.

| Platform | Release wheel |
|---|---|
| Windows x86-64 | `bluefire_nexus-3.0.0rc2-py3-none-win_amd64.whl` |
| Linux x86-64 | `bluefire_nexus-3.0.0rc2-py3-none-linux_x86_64.whl` |
| Intel macOS | `bluefire_nexus-3.0.0rc2-py3-none-macosx_11_0_x86_64.whl` |
| Apple Silicon macOS | `bluefire_nexus-3.0.0rc2-py3-none-macosx_11_0_arm64.whl` |

Download the matching wheel and `SHA256SUMS` from this release. Verify its SHA-256 against the row for that exact filename. Unsigned checksums detect mismatches but do not attest publisher identity.

Follow the [RC2 installation guide](https://github.com/Moneer-S/BlueFire-Nexus/blob/v3.0.0-rc2/docs/INSTALLATION.md) for platform-specific virtual-environment and launch commands. Install the intact wheel, then enter the one-time connection code printed by the launcher.

## Verified scope and limits

Hosted checks exercised installed native fixture execution and cleanup on Ubuntu 26.04.1 LTS x86-64, Windows Server 2025 AMD64, Intel macOS 15.7.9, and Apple Silicon macOS 26.6.2. Windows Server also exercised a bounded native process-tree cancellation witness; Windows 11 was not validated by these checks.

Linux additionally exercised the packaged browser workflow and a native generated-data loopback receiver fresh retest, including protected refusal, legitimate redacted acceptance, and retained policy. Apple Silicon file-access verification remains protocol/ABI only; it does not establish effective access.

Simulation uses synthetic results without performing native actions. Execute requires compatible methods, runner readiness, and explicit approval. AI-Off and local provider-fixture checks do not demonstrate live model inference. Fixture rule matches do not establish a changed-environment defense retest. The installed workspace compatibility check covered a copied development 3.0.0 workspace, saved versions, a finalized run, and its export; RC1 migration and rollback were not validated.

Native support varies by method and platform. Active Directory, AWS, and customer-stack validation remain unverified. S3 audit dispatch remains disabled. Remote runners and production EDR/SIEM collection integrations are not shipped.
